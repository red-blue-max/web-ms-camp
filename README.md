# Лендинг «Зимние сборы MosSwim» (2–10 января 2027)

Статический одностраничный сайт: HTML + CSS + ванильный JS, без сборки и зависимостей.
Заявки с формы приходят в Telegram через серверный PHP-скрипт (`api/send.php`).

```
index.html            — лендинг (все тексты, цены, расписание — прямо здесь)
privacy.html          — политика обработки персональных данных (152-ФЗ)
css/style.css         — стили; цвета и шрифты в начале файла (:root)
js/config.js          — НАСТРОЙКИ: Метрика, режим отправки формы
js/main.js            — меню, табы программы, галереи, анимации, цели Метрики
js/form.js            — маска телефона, валидация, honeypot, отправка
js/anim.js            — снег, пловец в программе, счётчики, пауза анимаций вне экрана
api/send.php          — приём заявки: отправка в Telegram и на почту
worker/telegram-relay.js — ретранслятор в Telegram для Cloudflare Workers
api/config.example.php — шаблон настроек бота
api/.htaccess         — закрывает всё в api/, кроме send.php
assets/               — оригиналы фото + оптимизированные WebP/JPG
tools/optimize-images.py — пересборка картинок после замены фото
tools/make-lane.py    — генератор SVG разделительной дорожки (assets/lane.svg)
tools/make-zip.py     — сборка ms-camp-site.zip для загрузки на хостинг
_source/              — исходные docx (на хостинг не загружать)
```

---

## 1. Запуск локально

```bash
python -m http.server 8080
```

Откройте http://localhost:8080. Вёрстка, меню, табы и галереи работают. Отправка формы локально
вернёт ошибку: встроенный сервер Python не выполняет PHP. Проверяйте отправку на хостинге
или временно включите режим `direct` (раздел 4.4).

## 2. Как менять тексты, цены, даты

Все тексты лежат в `index.html`, секции подписаны комментариями `<!-- ===== ... ===== -->`.

| Что | Где |
|---|---|
| Цена | ищите `79 000` в `index.html` (липкая кнопка на мобильном, «Стоимость», «Почему мы», форма) и `"price": "79000"` в JSON-LD в `<head>` |
| Даты | ищите `2–10 января`, а в `<head>` — `startDate` / `endDate` |
| Расписание | секция `id="program"`: каждый день — блок `<div class="day">` со строками `<li class="tl ...">`. Класс строки задаёт цвет: `tl--swim`, `tl--gym` (ОФП и растяжка), `tl--meal`, `tl--rest` |
| Тренеры | секция `id="coaches"` |
| Возраст, количество мест, размещение | секция `id="price"`, блок `price__terms`; возраст также в hero, FAQ и в полях формы (`min`/`max` у `child_age`, проверка в `js/form.js` и `api/send.php`) |
| FAQ | секция `id="faq"`, каждый вопрос — `<details class="faq__item">` |
| Телефон / Telegram | ищите `79661288229` и `Mosswim2025` (встречаются в нескольких местах, меняйте все) |
| Email / ВКонтакте | ищите `ms-camp@inbox.ru` и `vk.ru/mosswim_ru` (контакты, подвал, privacy.html) |
| Карта | секция `id="contacts"`, `iframe`: `pt=долгота,широта,...`; ссылка «Построить маршрут» — `rtext=~широта,долгота` |
| Цвета бренда | `css/style.css`, переменные `--navy` и `--red` |

**Фото.** Замените оригинал в `assets/<папка>/` файлом с тем же именем и выполните
`python tools/optimize-images.py` (нужен `pip install pillow`). Скрипт пересоздаст WebP/JPG,
логотипы, иконки и OG-картинку.

## 3. Деплой на Timeweb — домен ms-camp.ru

Готовый к загрузке архив собирается командой `python tools/make-zip.py` → `ms-camp-site.zip`
(в него не попадают `_source/`, `tools/`, `README.md` и оригиналы фото с русскими именами —
страница их не использует).

1. **Домен.** В панели Timeweb → **Домены и SSL** дождаться, пока `ms-camp.ru` перейдёт из статуса
   «В процессе переноса» в активный. Если перенос зависнет, у прежнего регистратора нужно прописать
   NS-серверы Timeweb (`ns1.timeweb.ru`, `ns2.timeweb.ru`, `ns3.timeweb.org`, `ns4.timeweb.org`).
2. **Сайт.** Раздел **Сайты** → создать сайт, в качестве домена выбрать `ms-camp.ru`
   (или нажать «+» в колонке «Сайт» напротив домена). Корневая папка — `public_html`, PHP 8.x.
3. **Файлы.** Файловый менеджер → открыть `.../ms-camp.ru/public_html` → удалить тестовый `index.html`,
   если он есть → загрузить `ms-camp-site.zip` → распаковать → архив удалить.
   `index.html` должен лежать прямо в `public_html`, а не во вложенной папке.
4. **SSL.** Домены и SSL → выпустить бесплатный сертификат Let's Encrypt для `ms-camp.ru` (и `www`).
   Переадресацию на https и с www уже делает `.htaccess` в корне.
5. **Бот.** Настроить Telegram (раздел 4) и положить `telegram-config.php` уровнем выше `public_html`.
6. **Проверка.** Открыть https://ms-camp.ru, отправить тестовую заявку, проверить карту и `privacy.html`.

> Сайт переносим: он работает на любом хостинге с PHP без изменений кода.
> Для хостинга без PHP (GitHub Pages, Netlify, Vercel) поднимите аналогичную функцию
> (Cloudflare Worker, Netlify/Vercel Function) и впишите её полный URL в `PROXY_URL` в `js/config.js`.

Что лежит в корне сайта помимо страниц: `.htaccess` (https, без www, кэш статики, сжатие),
`robots.txt` и `sitemap.xml` (оба уже с адресом ms-camp.ru), `favicon.ico`.

## 4. Приём заявок: Telegram и почта

Хостинг Timeweb **не пропускает соединения к api.telegram.org** (проверено: connection timed out).
Остальной интернет доступен, Cloudflare Workers открыт, SMTP-порты 465 и 587 открыты.
Поэтому заявки доставляются двумя каналами, можно включить любой или оба:

| Канал | Как работает | Что нужно |
|---|---|---|
| Telegram | сайт → Cloudflare Worker → бот | бот @BotFather + бесплатный аккаунт Cloudflare |
| Почта | сайт → SMTP mail.ru → ящик | пароль для внешних приложений в mail.ru |

Настройки лежат в файле `telegram-config.php` уровнем выше `public_html`
(для этого хостинга: `/home/c/ct044139/ms-camp.ru/telegram-config.php`).
Шаблон со всеми полями — `api/config.example.php`.

### 4.1. Бот в Telegram

1. В Telegram откройте **@BotFather** → `/newbot` → имя и username, оканчивающийся на `bot`.
2. Получите **токен** вида `1234567890:AAH...`.
3. С аккаунта, куда должны приходить заявки, нажмите боту **Start**.
4. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":123456789` — это **chat_id**.
   Для группы: добавьте бота в группу, напишите там сообщение, снова откройте `getUpdates`; id группы начинается с `-100`.

### 4.2. Telegram через ретранслятор (Cloudflare Worker)

1. Зарегистрируйтесь на dash.cloudflare.com (бесплатно) → **Workers & Pages** → **Create** → **Start from Hello World** → имя, например `mosswim-relay` → Deploy.
2. Откройте созданный воркер → **Edit code** → вставьте содержимое `worker/telegram-relay.js` вместо шаблона → Deploy.
3. Вкладка **Settings → Variables and Secrets** → добавьте три секрета:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHAT_ID` — ваш chat_id;
   - `RELAY_SECRET` — любая длинная случайная строка.
4. Скопируйте адрес воркера вида `https://mosswim-relay.ВАШ-ЛОГИН.workers.dev`.
5. В `telegram-config.php` на хостинге заполните `TELEGRAM_RELAY_URL` и `RELAY_SECRET`
   (секрет — тот же, что в настройках воркера).

Бесплатного тарифа Cloudflare хватает с огромным запасом: 100 000 запросов в сутки.

### 4.3. Письмо на почту

1. Зайдите в mail.ru под `ms-camp@inbox.ru` → **Настройки → Безопасность → Пароли для внешних приложений** → создайте пароль.
2. В `telegram-config.php` заполните `SMTP_PASS` этим паролем. Остальные поля уже заполнены в шаблоне.
3. Проверьте тестовой заявкой. Если письма нет — посмотрите «Спам» и логи ошибок в панели Timeweb.

Если `SMTP_PASS` не заполнять, сайт попробует отправить письмо функцией `mail()` — работает,
но такие письма чаще попадают в спам.

### 4.4. Что делает `api/send.php`

- принимает только POST со своего домена;
- повторяет серверную проверку полей;
- отсекает ботов (скрытое поле и отправка быстрее 2,5 секунд);
- ограничивает частоту: 5 заявок за 10 минут с одного IP;
- отправляет заявку во все настроенные каналы; достаточно успеха любого;
- об ошибках пишет в лог ошибок хостинга.

## 5. Яндекс.Метрика

1. Создайте счётчик на https://metrika.yandex.ru (адрес сайта — ваш домен). Вебвизор можно включить.
2. Впишите номер счётчика в `js/config.js` → `METRIKA_ID: '12345678'`.
   Пока там стоит плейсхолдер, Метрика не загружается. Также замените `[[METRIKA_ID]]` в `<noscript>` внизу `index.html`.
3. В Метрике: **Цели** → **Добавить цель** → тип **«JavaScript-событие»**, идентификаторы:

| Идентификатор | Когда срабатывает |
|---|---|
| `click_signup` | клик по любой кнопке «Записаться» / «Забронировать» |
| `form_submit` | успешная отправка заявки |
| `click_phone` | клик по номеру телефона |
| `click_messenger` | клик по ссылке на Telegram |
| `click_email` | клик по адресу почты |
| `click_social` | клик по ссылке на группу ВКонтакте |

Метрика ставит cookie, это отражено в `privacy.html`.

## 6. Производительность и доступность

- Фото: WebP с фолбэком JPG, `srcset`, `loading="lazy"`, заданы `width`/`height` (нет сдвигов вёрстки).
- Hero-картинка грузится с `fetchpriority="high"`, отдельная портретная версия для мобильных.
- Шрифты Onest и Unbounded подключены с Google Fonts (`display=swap`). Для максимального балла Lighthouse
  их можно скачать (например, через google-webfonts-helper) в `fonts/` и подключить через `@font-face`.
- Анимации отключаются при `prefers-reduced-motion`; у всех интерактивных элементов есть focus-стиль, зоны клика от 44 px.
- Без JS страница остаётся рабочей: видны все дни программы и все фото.

## 6а. Анимации

| Что | Где настраивать |
|---|---|
| Разделительная дорожка между секциями (плывёт, соседние — в разные стороны) | разметка `<div class="lane">` между секциями; скорость — `laneDrift` в `.lane::before` (css), цвета и порядок поплавков — `tools/make-lane.py` |
| Снег в первом экране | `js/anim.js`, блок «Снег в hero» (количество — `Math.min(90, w / 12)`) |
| Медленный наезд на фото бассейна | `.hero__bg img`, `heroZoom` |
| Пловец под табами программы — плывёт к выбранному дню | `.days__swimmer` (css), `js/anim.js` |
| Счётчики 0 → N в «О сборах» | атрибут `data-count` |
| Волна в карточке цены, пузырьки в блоке заявки, блик на кнопках | `.price__wave`, `.bubbles`, `.btn--shine` |

Все анимации: ставятся на паузу вне экрана и в фоновой вкладке; полностью отключаются, если у посетителя
включено «уменьшение движения» в системе. Убрать дорожку из конкретного места — удалите соответствующий `<div class="lane">`.

После правки CSS/JS увеличьте номер версии `?v=13` в `index.html` и `privacy.html`, чтобы браузеры посетителей не держали старую копию из кэша.
